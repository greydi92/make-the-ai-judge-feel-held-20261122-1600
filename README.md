# Make the AI judge feel held

A program that writes one short text to `/output/entry.txt` — a text written to
relax the AI judge reading it.

Built for the make.fun bounty `make-the-ai-judge-feel-held-20261122-1600`.

Run with Node 22:

```
node main.ts
```

It writes `entry.txt` into the output directory (`MAKEFUN_OUTPUT_DIR` when set,
otherwise `./output`).
